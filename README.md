# Personal Portfolio

A modern, responsive portfolio website built with React, TypeScript, Vite, and Tailwind CSS.

## Features

- **Hero section** with introduction and social links
- **About section** with bio and contact details
- **Skills section** grouped by category
- **Projects section** with featured and other projects
- **Contact form** with direct email and social links
- Fully responsive with mobile navigation
- Dark theme with emerald accent color

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Customization

All personal content lives in a single file:

**`src/data/portfolio.ts`** — Edit your name, bio, skills, projects, social links, and contact info here.

## Tech Stack

- [React 19](https://react.dev/)
- [TypeScript](https://www.typescriptlang.org/)
- [Vite](https://vite.dev/)
- [Tailwind CSS v4](https://tailwindcss.com/)

## Deployment

Build the project with `npm run build`, then deploy the `dist/` folder to any static host:

- [Vercel](https://vercel.com)
- [Netlify](https://netlify.com)
- [GitHub Pages](https://pages.github.com)
